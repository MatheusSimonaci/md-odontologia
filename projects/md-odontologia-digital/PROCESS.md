# 💎 Essência do Sucesso — Playbook MD Odontologia

Este documento destila as estratégias validadas para replicação em projetos de alto padrão.

## 1. Identidade & Estética de Luxo
*   **DNA da Marca**: Extrair a paleta cromática e tipografia diretamente da logo do cliente. O site deve ser uma extensão da marca física, não um template genérico.
*   **Luxo por Subtração**: A autoridade é construída pelo que se remove. Elimine ruídos visuais (contadores, excesso de cores, ícones técnicos) para dar espaço à elegância editorial.
*   **Paleta Quente**: Trocar brancos e pretos puros por tons orgânicos (Ex: Fundo `Creme`, Texto `Espresso`).

## 2. Refino Editorial e Visual
*   **Tratamento de Imagem via CSS**: Fotos reais devem receber overlays e filtros (saturate, contrast, sepia) diretamente no código para garantir coesão cromática com o design.
*   **Hero de Autoridade**: O topo do site deve funcionar como uma capa de revista — tipografia serifada de alto contraste sobre um retrato editorial da equipe.

## 3. Inteligência e Estrutura
*   **Mapeamento Humano (Manus IA)**: Use pesquisa profunda para identificar toda a equipe e especialidades antes de codar. O site vale o quanto a equipe transmite confiança.
*   **Arquitetura Mobile-First**: O código base é para 375px. Layouts desktop são adições via media queries, nunca o contrário.
*   **Performance Invisível**: Animações restritas a `transform` e `opacity`. Sem frameworks, sem dependências, apenas HTML/CSS puro de alta performance.
